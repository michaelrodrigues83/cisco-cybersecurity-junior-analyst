# 🦅 Trilha Cisco: Analista Júnior de Segurança Cibernética

Bem-vindo ao repositório central dedicado à documentação técnica de laboratórios práticos, arquitetura de redes seguras e inteligência de ameaças desenvolvidos ao longo da formação **Analista Júnior de Segurança Cibernética** (*Cybersecurity Junior Analyst*) da **Cisco Networking Academy**.

O objetivo deste espaço é demonstrar o desenvolvimento de competências técnicas em segurança defensiva, análise de tráfego e automação de operações de segurança (SOC), servindo de sustentação prática para as minhas análises macro em Governança, Riscos e Conformidade (GRC).

---

## 🎯 Contexto Acadêmico e Desenvolvimento Técnico

Este portfólio une a base de conhecimento de engenharia de segurança à formação de nível superior, evidenciando uma trilha contínua de capacitação profissional:

* **Formação Acadêmica:** Cursando Segurança da Informação pela **Faculdade de Tecnologia Prof. José Arana Varela (Araraquara)**.
* **Trilha Tecnológica:** Cybersecurity Junior Analyst — **Cisco Networking Academy** (*Em Andamento*).
* **Frentes Complementares de GRC:** Governança e Frameworks (ISO/IEC 27001 via Udemy) / Privacidade e Proteção de Dados (LGPD via Data Privacy Brasil).
